Pseudo-class adalah cara CSS memilih elemen berdasarkan keadaan (state) tertentu.
button:hover {
    background: red;
}
hover = keadaan ketika mouse berada di atas elemen.


Apa itu Pseudo-Element?

Kalau pseudo-class memilih keadaan, pseudo-element memilih bagian tertentu dari elemen.
HTML(<p>Halo</p>)

p::before {
    content: "uhuy";
}




=====yang sering dipake========
Mantap. Kalau mau bikin website terasa hidup tanpa JavaScript, ada beberapa "jurus CSS" yang dipakai hampir di semua website modern.

---

# 1. Tombol Membesar Saat Hover

```html
<button class="btn">Masuk</button>
```

```css
.btn {
    padding: 1rem 2rem;
    transition: 0.3s;
}

.btn:hover {
    transform: scale(1.05);
}
```

Efek:

```text
Mouse masuk
↓
Tombol membesar sedikit
```

---

# 2. Tombol Tertekan Saat Diklik

# 7. Underline Navbar Animasi

Ini favorit developer frontend.

```html
<a href="#">Home</a>
```

```css
a {
    position: relative;
    text-decoration: none;
}

a::after {
    content: "";
    position: absolute;
    left: 0;
    bottom: -5px;

    width: 0;
    height: 2px;

    background: green;
    transition: .3s;
}

a:hover::after {
    width: 100%;
}
```

Efek:

```text
Hover
↓
Garis tumbuh dari kiri ke kanan
```

# 15. Efek Floating

```css

    animation: float 3s infinite ease-in-out;
}

        transform: translateY(0);

        transform: translateY(-10px);
    }
}
```

Efek:

```text
Naik turun terus
```

Kalau aku lihat levelmu sekarang (sudah paham Flexbox, class, BEM dasar), yang paling penting dikuasai dulu adalah:

```css
:hover
:active
:focus
transition
transform
```

Karena sekitar **80% efek interaktif CSS modern** sebenarnya cuma kombinasi dari 5 hal itu.

Contoh yang sangat sering kamu lihat:

```css
.card {
    transition: .3s;
}

.card:hover {
    transform: translateY(-10px);
}
```

atau

```css
.btn {
    transition: .3s;
}

.btn:hover {
    transform: scale(1.05);
}
```

Begitu paham `hover + transition + transform`, website buatanmu langsung terasa jauh lebih profesional meskipun belum memakai JavaScript sama sekali. 🚀
